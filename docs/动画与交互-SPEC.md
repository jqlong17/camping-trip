# 露营之旅 — 动画与交互细节 SPEC

> 状态：2026-08-30 落地中  
> 从属：[游戏设计-SPEC.md](./游戏设计-SPEC.md)  
> 目标：角色四向行走 + 道具仪式动画，让营地「有生活感」

---

## 1. 角色精灵图（必做）

### 1.1 布局约定

每个可选角色一份行走表：

```
game/assets/cast/c{N}_walk.png
```

| 约定 | 值 |
|------|-----|
| 单帧尺寸 | **40×40** |
| 行（facing） | `0=下(朝玩家)` `1=左` `2=右` `3=上(背影)` |
| 列（帧） | `0=站立` `1=走1` `2=走2` |
| 总图 | **120×160**（3 列 × 4 行） |
| 缩放 | 始终 **nearest**；营地绘制高度约 28px |

```
+----+----+----+
| D0 | D1 | D2 |  ↓
+----+----+----+
| L0 | L1 | L2 |  ←
+----+----+----+
| R0 | R1 | R2 |  →
+----+----+----+
| U0 | U1 | U2 |  ↑
+----+----+----+
```

### 1.2 运行时

| 字段 | 说明 |
|------|------|
| `player.facing` | 0..3，与上表行一致 |
| `player.walkFrame` | 站立=0；移动时在 1↔2 切换 |
| `player.walkTimer` | 累计时间，约 0.18s 换帧 |

- 松开方向键 → 回到该向的站立帧 `*0`。  
- 选人确认后加载对应 `c{N}_walk.png`；缺失则回退 `c{N}.png` 单帧。

### 1.3 美术约束（与全局像素规范一致）

- 大色块、连续描边、**禁止**盐胡椒噪点。  
- 背影（上）不露正脸五官；左右为水平镜像或镜像微调。  
- 九人身份保持：眼镜上班族 / 草帽姑娘 / …（见 `cast/names.txt`）。

### 1.4 制作优先级

1. **P0**：脚本从立绘生成四向表（镜像 + 背影简化）— 已完成。  
2. **P1 / P2（DEV-026）**：**九人全量四向走帧精修**已接入 `c{N}_walk.png`（真四向，非仅镜像）。  
3. 后续可再手修个别角色细节。

## 2. 地图世界状态（必做）

营地不只是静态 tile，要有**可变化物件**：

| 状态 | 默认 | 变化 |
|------|------|------|
| `tentOpen` | `false`（收纳/未搭） | 靠近帐篷位 + 使用「帐篷」→ 搭起；再一次可收起 |
| `brewActive` | `false` | 手冲仪式进行中/刚完成时，地图出现冲煮台 + 蒸汽 |
| `lanternOn` | `false` | 入夜营火旁点灯（已有） |
| `potSimmer` | `false` | 使用小锅后短暂冒泡 |

绘制层顺序：地面 → 岸 → 静态 prop → **动态世界物件** → 角色 → 光线罩。

## 3. 道具仪式（必做）

选中下屏装备并按 **A / 空格** 时：若该道具有仪式，则进入 **`ritual` 叠加态**（仍属 `scene=="play"`，用 `ritual.kind` 区分），而不是只弹 toast。

### 3.1 手冲咖啡 `drip`（招牌）

**触发**：选中「手冲」+ A（任意空地可开始；靠近河岸文案更佳）。

**流程（3 步，下屏点「下一步」或 A）**：

| 步 | 标题 | 上屏 | 地图同步 |
|----|------|------|----------|
| 1 | 闷蒸 | 特写：滤杯+粉床微润 | 脚边出现冲煮台 |
| 2 | 绕圈注水 | 水流螺旋 + 蒸汽帧 | 蒸汽粒子动画 |
| 3 | 分享入杯 | 分享壶→杯子 | `brewActive` 保持一会儿；可推进时段 |

结束后回自由移动；toast：「第一口……周末真好。」

资产：`game/assets/ritual/drip_1..3.png`（16-bit 像素特写，120×76，上屏 ×2 nearest；DEV-034）；地图 `brew_kit` + `steam_*`。

### 3.2 帐篷 `tent`

| 动作 | 条件 | 表现 |
|------|------|------|
| 搭起 | 靠近帐篷位 `(11,10)` 附近且未打开 | 2～3 帧展开 → `tile_tent_open`；`tentOpen=true` |
| 收起 | 已打开再使用 | 收纳帧 → `tile_tent_packed` |

资产：`tile_tent_packed.png` / `tile_tent_open.png`（可从现有 tent 派生）。

### 3.3 小锅 `pot`

靠近营火时：短仪式「烧开」；地图营火旁冒泡 2～3 秒。

### 3.4 钓竿 `rod`

靠近小溪：进入 **4 帧短动画**（抛竿→等待→中鱼→结束），自动播放，A 可跳过；并触发小鱼跃出。资产：`world/fish_anim_0..3.png`。

### 3.5 杯子 / 扇子

- 杯子：需已完成至少一次手冲才「有味道」。  
- 扇子：**4 帧扇风短动画**（`world/fan_anim_0..3.png`），自动播放，A 可跳过。

### 3.6 点灯（已有，保留）

入夜 + 靠近营火 + A → 灯晕；与仪式可并存。

### 3.7 夜晚氛围（DEV-035）

光线罩之后再画，才压不暗：

- **星星**：1–2px 暖白矩形，少量十字星，黄昏/黎明淡出
- **流星**：偶发斜向硬像素拖尾（无模糊）
- **萤火虫**：2×2 暖黄亮点 + 十字微晕，只在入夜/深夜
- **风**：树冠/灌木轻微摇摆；硬像素落叶从左往右

## 4. UI / 双屏

| 状态 | 上屏 | 下屏 |
|------|------|------|
| 自由移动 | 营地 + 世界动画 | 背包 + 过一会儿 / 回家 |
| `ritual.drip` | 冲煮特写 + 步骤名 | 「A 下一步」；可取消 |
| `ritual.rod` / `ritual.fan` | 4 帧短动画放大 | 自动播放；A 跳过 |
| `ritual.tent` | 营地（帐篷播动画） | 「搭帐篷中…」短阻输入 |

仪式中禁止走路；B / Esc 可取消（手冲取消则撤掉未完成冲煮台）。

## 5. 验收（playtest 扩展）

`love game --playtest` 须覆盖：

1. 完整周末环（已有）  
2. 营地内 **四向各走至少 1 步**（截图可含）  
3. **搭帐篷** → 地图帐篷变为打开态  
4. **手冲三步** → 出现仪式画面与地图蒸汽  
5. 仍以 `PASS` 结束  

产物目录不变：`playtest/`。

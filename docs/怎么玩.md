## 完整流程

```
标题 → 序章 →（首次选角色）→ 选择目的地 → 出发 → 营地 → 回家 → 书桌 TN 手帐存档 → 标题
```

第二次起不再强制选角；标题里可「切换角色」。回家后摊开窄高手帐写日记才算存档。
日记上屏只保留像素笔迹氛围；下屏左右翻三页感想，按 A 保存回标题。
标题「继续」留在主菜单等贴图，提示「正在抵达营地…」后进营，不会跳去出发分镜。
角色确认后用左右选择「林间营地 / 海边营地」。出发分镜按 A；若同样提示，等一下会自动进营。海边是同一目的地的昼夜变化，
清晨看日出、黄昏看日落；旧存档没有目的地字段时按林间处理。

## 操作

### 标题 / 序章 / 选人 / 过场

方向键选、A 确认；序章按 A 翻句。  
**B / Esc**：序章～营地～日记中途会弹出确认（返回将丢失本趟进度）；图鉴/关于仍直接回标题。  
**切换角色**：标题菜单进入，改完保存回标题。  
**装备图鉴**：标题选入后，下屏点格子或方向键翻页，上屏看用法；B / A 返回。  
**关于**：标题选入后看作品说明；B / A 返回。

### 营地

| 操作 | 作用 |
|------|------|
| 方向键 / WASD | **四向走动**（面向会变） |
| 下屏点装备 | **直接使用**（真机点一下即可；电脑也可点） |
| **靠近挂果树 + A** | **摘果**（每棵本趟有限）；下屏收获条显示 |
| 帐篷 | **站在平地上**按 A：米白尖顶帐篷直接展开；再按一次收起 |
| 手冲 | 进入完整仪式；完成后点杯子：选杯 → 关注点 → 三帧品尝（杯型改口感） |
| 泡茶 | 与手冲同级完整仪式；可与咖啡壶并存选喝 |
| 做饭 | **替代扇子**：选菜系（烧烤/寿司/火锅/烤串/炖锅）× 火候 × 调味 → 三帧烹饪 |
| 钓竿（水边） | 林间溪边或海边浪线旁使用；**选点/饵/铅/竿法 + 四帧钓鱼特写** |
| 靠近溪水 | 溪水环境音变响；水面有波光 |
| 靠近小鸟 | 偶发鸟鸣 |
| 趟水 | 脚边有溅水点 |
| 仪式中 | 点选项或左右切换，再点一次／按 A 确认；点取消或 B 退出 |
| 手冲 | 选豆→研磨→滤杯→滤纸→水温→冲次→闷蒸/注水/入杯；左右切换选项 |
| 泡茶 | 选茶→投量→茶器→温杯→水温→出汤次数→注水/闷泡/出汤；与咖啡可并存；杯子可左右选喝哪种 |
| 杯子 | 需先完成手冲或泡茶；一壶三口，喝空可再冲/再泡 |
| 做饭 | 选菜系（烧烤/寿司等）× 火候 × 调味 → 三帧烹饪 |
| 时间 | 右上角 `D1 午后`；自动缓推；**X / R / 右肩**可快推；要等 **入夜/深夜** 才能点火 |
| **点灯** | **入夜后**走到营地中央**篝火旁**（约 2 格内）按 **A**；**不必**先选装备；成功会提示「点亮了露营灯」并亮火光 |
| 「收拾回家」 / Y / H | 点过灯后可回家 → 日记 |

营地里会偶尔看见：**小鱼跃出**、**小鸟从树上飞到地上再飞回**（三种）、**树巢**、**蝴蝶 / 蜻蜓**；风会轻轻吹动树冠，偶有落叶。夜里可抬头看星星，偶尔有流星，萤火虫会亮起来。

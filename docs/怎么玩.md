## 完整流程

```
标题 → 序章 →（首次选角色）→ 出发 → 营地 → 回家 → 书桌日记存档 → 标题
```

第二次起不再强制选角；标题里可「切换角色」。回家后写日记才算存档。

## 操作

### 标题 / 序章 / 选人 / 过场

方向键选、A 确认；序章按 A 翻句。  
**切换角色**：标题菜单进入，改完保存回标题。  
**装备图鉴**：标题选入后，下屏点格子或方向键翻页，上屏看用法；B / A 返回。  
**关于**：标题选入后看作品说明；B / A 返回。

### 营地

| 操作 | 作用 |
|------|------|
| 方向键 / WASD | **四向走动**（面向会变） |
| 下屏点装备 + A/空格 | 使用 |
| **靠近挂果树 + A** | **摘果**（每棵本趟有限）；下屏收获条显示 |
| 帐篷 | **站在平地上**按 A，自己选落点；靠近再按可收起 |
| 手冲 | 进入 **三步仪式**；完成后点杯子可选 **白瓷/蓝搪瓷/木柄** 再喝（一壶三口） |
| 钓竿（溪边） | **四帧钓鱼特写**；成功记入鱼种 |
| 靠近溪水 | 溪水环境音变响；水面有波光 |
| 靠近小鸟 | 偶发鸟鸣 |
| 趟水 | 脚边有溅水点 |
| 仪式中 A | 下一步 / 跳过；取消 / B / Esc | 取消手冲 |
| 手冲 | 选豆→研磨→滤杯→滤纸→水温→冲次→闷蒸/注水/入杯；左右切换选项 |
| 泡茶 | 选茶→投量→茶器→温杯→水温→出汤次数→注水/闷泡/出汤；与咖啡可并存；杯子可左右选喝哪种 |
| 杯子 | 需先完成手冲或泡茶；一壶三口，喝空可再冲/再泡 |
| 小锅 | 靠近营火冒泡 |
| 时间 | 右上角 `D1 09:00` 钟点；自动缓推；**R / 右肩键**快进到下一天上午 |
| 入夜营火旁 A | 点灯 |
| 「收拾回家」 / Y / H | 回家 → 日记 |

营地里会偶尔看见：**小鱼跃出**、**小鸟从树上飞到地上再飞回**（三种）、**树巢**、**蝴蝶 / 蜻蜓**；风会轻轻吹动树冠，偶有落叶。夜里可抬头看星星，偶尔有流星，萤火虫会亮起来。

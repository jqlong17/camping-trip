# 露营之旅 — 动画与交互细节 SPEC

> 状态：2026-08-30 落地中  
> 从属：[游戏设计-SPEC.md](./游戏设计-SPEC.md)  
> 目标：角色四向行走 + 道具仪式动画，让营地「有生活感」

## 1. 角色精灵图（必做）

### 1.1 布局约定

每个可选角色一份行走表：

```
game/assets/cast/c{N}_walk.png
```

| 约定 | 值 |
|------|-----|
| 单帧尺寸 | **40×40** |
| 行（facing） | `0=下(朝玩家)` `1=左` `2=右` `3=上(背影)` |
| 列（帧） | `0=站立` `1=走1` `2=走2` |
| 总图 | **120×160**（3 列 × 4 行） |
| 缩放 | 始终 **nearest**；营地绘制高度约 28px |

```
+----+----+----+
| D0 | D1 | D2 |  ↓
+----+----+----+
| L0 | L1 | L2 |  ←
+----+----+----+
| R0 | R1 | R2 |  →
+----+----+----+
| U0 | U1 | U2 |  ↑
+----+----+----+
```

### 1.2 运行时

| 字段 | 说明 |
|------|------|
| `player.facing` | 0..3，与上表行一致 |
| `player.walkFrame` | 站立=0；移动时在 1↔2 切换 |
| `player.walkTimer` | 累计时间，约 0.18s 换帧 |

- 松开方向键 → 回到该向的站立帧 `*0`。  
- 选人确认后加载对应 `c{N}_walk.png`；缺失则回退 `c{N}.png` 单帧。

### 1.3 美术约束（与全局像素规范一致）

- 大色块、连续描边、**禁止**盐胡椒噪点。  
- 背影（上）不露正脸五官；左右为水平镜像或镜像微调。  
- 九人身份保持：眼镜上班族 / 草帽姑娘 / …（见 `cast/names.txt`）。

### 1.4 制作优先级

1. **P0**：脚本从立绘生成四向表（镜像 + 背影简化）— 已完成。  
2. **P1 / P2（DEV-026）**：**九人全量四向走帧精修**已接入 `c{N}_walk.png`（真四向，非仅镜像）。  
3. 后续可再手修个别角色细节。

## 2. 地图世界状态（必做）

营地不只是静态 tile，要有**可变化物件**：

| 状态 | 默认 | 变化 |
|------|------|------|
| `tentOpen` | `false`（收纳/未搭） | 靠近帐篷位 + 使用「帐篷」→ 搭起；再一次可收起 |
| `brewActive` | `false` | 手冲仪式进行中/刚完成时，地图出现冲煮台 + 蒸汽 |
| `lanternOn` | `false` | 入夜营火旁点灯（已有） |
| `potSimmer` | `false` | 使用小锅后短暂冒泡 |

绘制层顺序：地面 → 岸 → 静态 prop → **动态世界物件** → 角色 → 光线罩。

## 3. 道具仪式（必做）

选中下屏装备并按 **A / 空格** 时：若该道具有仪式，则进入 **`ritual` 叠加态**（仍属 `scene=="play"`，用 `ritual.kind` 区分），而不是只弹 toast。

### 3.1 手冲咖啡 `drip`（招牌）

工程权威：[手冲模块-SPEC.md](./手冲模块-SPEC.md)（`game/drip_brew.lua`，相位表驱动）。

**触发**：选中「手冲」+ A。壶里还有咖啡时会转到喝；喝空或尚未冲则开新一壶（**可反复冲煮**）。

**配方步骤（下屏左右选 · A 确认）**：见手冲模块 SPEC §4–§6（豆 / 研磨 / 滤杯 / 滤纸 / 水温 / 冲次 / 三步冲煮）。

完成后自动喝第一口；参数组合算出口感短句。一壶最多三口；喝完可再选手冲重来。

资产：`ritual/drip/drip_1..3.png`；`ritual/drip/dripper_*.png`、`bean_*.png`、`grind_*`、`temp_*`、`pours_*`、`drip_paper.png`；地图 `brew_kit` + `steam_*`。

### 3.1b 泡茶 `tea`（对齐手冲）

工程权威：[泡茶模块-SPEC.md](./泡茶模块-SPEC.md)（`game/tea_brew.lua`）。

背包格「泡茶」：选茶叶 → 投茶量 → 茶器 → 温杯烫壶 → 水温 → 出汤次数 → 注水/闷泡/出汤。茶壶与咖啡壶状态分离；杯子在两者都有剩时可左右选喝哪种。

资产：`ritual/leaf_*`、`ware_*`、`tea_amount_*`、`tea_temp_*`、`tea_steeps_*`、`tea_rinse.png`、`tea_1..3.png`、`gear_tea.png`。

### 3.2 帐篷 `tent`

| 动作 | 条件 | 表现 |
|------|------|------|
| 搭起 | 未搭起 + 站在可走平地按 A | 唯一的米白尖顶帐篷直接展开，不进入仪式 |
| 收起 | 已搭起再使用 | 直接收起 |

模块：`tent_gear.lua`；装备格与地图共用资产：`gear/tent.png`。

### 3.3 小锅 `pot`

靠近营火时：短仪式「烧开」；地图营火旁冒泡 2～3 秒。

### 3.4 钓竿 `rod`

靠近小溪：选钓点/饵/铅 → 抛竿确认 → 竿法 → **4 帧仪式特写**（抛→等→咬→起；另有 miss 帧）。

资产：`ritual/fish/fish_1..4.png`（**120×76**）；选配图标 `spot_*` / `bait_*` / `sinker_*` / `style_*`（48×48）。DEV-070 文生图 v2 重切钓点与仪式帧。

### 3.4b 摘果

靠近挂果树（地图树冠可见果点）按 A：摘 1 个入账；每棵本趟库存有限。资产：`world/fruit_icon.png`、树上果点用色块绘制。

### 3.5 杯子 / 扇子

- 杯子：需已有咖啡或茶；9 杯型带 `coffeeMod`/`teaMod` 缀入口感句；确认后选关注点，再播 `ritual/cup/sip_1..3` 抬杯特写（`cup_sip.lua`）。  
- 扇子：**4 帧扇风短动画**（`world/fan_anim_0..3.png`），自动播放，A 可跳过。

### 3.6 点灯（已有，保留）

入夜 + 靠近营火 + A → 灯晕；与仪式可并存。

### 3.7 夜晚氛围（DEV-035）

光线罩之后再画，才压不暗：

- **星星**：1–2px 暖白矩形，少量十字星，黄昏/黎明淡出
- **流星**：偶发斜向硬像素拖尾（无模糊）
- **萤火虫**：2×2 暖黄亮点 + 十字微晕，只在入夜/深夜
- **风**：树冠/灌木轻微摇摆；硬像素落叶从左往右

## 4. UI / 双屏

| 状态 | 上屏 | 下屏 |
|------|------|------|
| 自由移动 | 营地 + 世界动画 | 背包 + 过一会儿 / 回家 |
| `ritual.drip` | 冲煮特写 + 步骤名 | 「A 下一步」；可取消 |
| `ritual.rod` / `ritual.fan` | 4 帧短动画放大 | 自动播放；A 跳过；钓鱼成功时下屏显示鱼种 |
| `ritual.tent` | 营地（帐篷播动画） | 「搭帐篷中…」短阻输入 |

仪式中禁止走路；B / Esc 可取消（手冲取消则撤掉未完成冲煮台）。

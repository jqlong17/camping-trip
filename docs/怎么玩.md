## 完整流程

```

```

## 操作

### 标题 / 序章 / 选人 / 过场

与此前相同：方向键选、A 确认；序章按 A 翻句。

### 营地

| 操作 | 作用 |
|------|------|
| 方向键 / WASD | **四向走动**（面向会变） |
| 下屏点装备 + A/空格 | 使用 |
| 帐篷（靠近空地） | **搭起 / 收起**，地图外观会变 |
| 手冲 | 进入 **三步仪式**（闷蒸→注水→入杯）；地图出现冲煮台与蒸汽 |
| 仪式中 A | 下一步；取消 / B / Esc | 取消手冲 |
| 杯子 | 需先完成手冲才有味道 |
| 小锅 | 靠近营火冒泡 |
| X / 「过一会儿」 | 推进时段 |
| 入夜营火旁 A | 点灯 |
| 「收拾回家」 / Y / H | 回家 |

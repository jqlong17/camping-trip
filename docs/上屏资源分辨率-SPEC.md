# 上屏资源分辨率与内存预算 SPEC

> 状态：DEV-108 · 2026-09-02  
> 范围：除泡茶以外的 TOP（400×240）主视觉。泡茶由并行任务独立维护。

## 1. 硬约束

1. `gear/`、仪式 catalog 的 48×48/48×40 图片只用于下屏目录，不得放大充当上屏主视觉。
2. 上屏仪式预览统一放在 `game/assets/previews/`，由 `docs/promo` 或
   `docs/characters` 高分辨率制作源直接降采样到 **320×180**；禁止“先做
   48×48/120×76/160×120，再放大上屏”。
3. 全屏分镜保留有效内容 **400×240**，POT 容器可为 512×256；运行时只裁出
   左上 400×240，1:1 绘制。已经清晰的分镜不得重做。
4. 预览构建只允许 source-direct 裁切、CKE/ECSP、等比缩小和限色；不得把目录
   图标作为输入。缺制作源时必须登记为待文生图，不得放大旧图冒充。
5. 3DS 使用 T3X/POT：320×180 会落入 512×256 纹理，RGBA8888 未压缩上限约
   **512 KiB/张**。运行时只保留一个 `topPreview`，切选项时替换，预览驻留预算
   **≤512 KiB**，禁止一次加载整套预览。

## 3. 资源角色

- 目录图标：`game/assets/gear/**`、`game/assets/ritual/<module>/*.png`
- 上屏预览：`game/assets/previews/ritual/<module>/*.png`
- 图鉴预览：`game/assets/previews/codex/*.png`
- 选角预览：`game/assets/previews/cast/*.png`
- 全屏分镜：`game/assets/scenes/*/story/*.png`

Story Atlas 的资源对象包含 `displayRole`：`directory-icon`、`catalog-icon`、
`top-preview`、`top-frame`、`runtime-media`；节点预览卡直接显示角色，避免再把
同名目录图和上屏图混为一张。

## 4. 构建与来源

`python3 scripts/build-top-previews.py` 从仓库内高分辨率制作源构建全部非茶预览。
脚本的 `ASSET_PROVENANCE` 是 Story Atlas 血缘权威。PHASE-003/004/006 使用
`dripper_{id}_chroma_gen_ref.png`、`drip_paper_chroma_gen_ref.png` 与
`drip_pours_{n}_chroma_gen_ref.png` 九个独立纯绿幕源，经 CKE 直接构建。
旧木架组合滤杯源和“滤纸＋三冲次”组合源只作历史参考，不再是 active 上游。

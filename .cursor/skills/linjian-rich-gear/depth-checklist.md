# 丰富度展开清单（按主题）

做新内容时勾选；不足则补 SPEC / 选项，勿直接标 done。

## 通用（任何 A/B/C）

- [ ] SPEC 写明玩家「感觉到有讲究」的一句话  
- [ ] ≥3 选择维 **或** ≥5 仪式相位  
- [ ] 每维 ≥2 选项（仪式 catalog 常用 3–5）  
- [ ] 结果短句或地图可见差  
- [ ] 可反复或明确一次性（默认倾向可反复）  
- [ ] 独立 `game/*.lua` + 资源命名表  
- [ ] playtest 覆盖主路径  

## A · 仪式（手冲 / 泡茶 / 未来炊事）

- [ ] 原料 catalog  
- [ ] 用量或研磨/投量  
- [ ] 器具 catalog  
- [ ] 准备确认相（滤纸/温杯等）  
- [ ] 温度或火候  
- [ ] 次数/时长维  
- [ ] 3 帧过程特写  
- [ ] 口感/氛围公式 + 修正表  

## B · 选配 · 帐篷

- [ ] 颜色 ≥3（如沙、松绿、雾蓝）  
- [ ] 款式 ≥2（穹顶 / 隧道 / …）  
- [ ] 至少一处结构差（门帘、窗、灯带）  
- [ ] 地图 `tent` 贴图随选择切换  
- [ ] 下屏预览图标随 pick 变  

## B · 选配 · 露营灯

- [ ] 款式 ≥3（煤油、电灯、纸灯笼…）  
- [ ] 光色 ≥2（暖/冷）影响夜里 tint 或光晕色  
- [ ] 开合仍保留；选配在装备或仪式入口  
- [ ] 图标 + 可选小特写  

## C · 登山徒步包

- [ ] 背景套：至少晨/昏或晴/雾两张像素气氛图  
- [ ] 装备 ≥3：杖、壶、地图/帽等  
- [ ] 图鉴或下屏说明各一行  
- [ ] 可选：短「歇脚/喝水」反馈，不要空背包  

## 与手冲对齐自检

问自己：若玩家刚玩完泡茶，再玩这个，会不会觉得「一下变简陋」？  
会 → 加一维选择或加两步相位再交付。
